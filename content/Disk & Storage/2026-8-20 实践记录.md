# 任务:通过 Block IO 读取磁盘的 MEDIA(EFI_BLOCK_IO_MEDIA)

## 实现思路

Block IO 协议由控制器驱动(AHCI / NVMe / USB Mass Storage)在设备连接时安装,每个块设备句柄上挂一个实例。`BlkIo->Media` 指针直接指向介质属性结构,拿到协议实例后。

整体路径:枚举 → 取实例 → 读字段 → MyPrint 输出:

1. `LocateHandleBuffer(ByProtocol, gEfiBlockIoProtocolGuid)` 枚举所有块设备句柄
2. `HandleProtocol` 从句柄取 `EFI_BLOCK_IO_PROTOCOL *BlkIo`
3. 直接读 `BlkIo->Media` 的字段(BlockSize / LastBlock / MediaId / MediaPresent / LogicalPartition …),容量 = `MultU64x32(LastBlock+1, BlockSize)`(64 位乘防溢出)
4. 用工程自研 `MyPrint` 库直写 COM1 串口输出(RELEASE 构建 DEBUG() 为空,所以用 MyPrint)


## 实现步骤

### 1. 创建模块并注册构建

`OemJYTianPkg\JYTianDxeModule\ReadDiskMedia.c/.inf`(DXE_DRIVER),注册到 `JYTianDxeModule.cif/.sdl`(Token=1)与 `Build\Platform.dsc [Components]`。

### 2. 枚举 BlockIo 句柄并取协议实例

```c
Status = gBS->LocateHandleBuffer (ByProtocol, &gEfiBlockIoProtocolGuid,
                                  NULL, &HandleCount, &HandleBuffer);
// 遍历:
Status = gBS->HandleProtocol (HandleBuffer[Index],
                              &gEfiBlockIoProtocolGuid, (VOID **)&BlkIo);
```

### 3. 读取 MEDIA 字段并打印

```c
Media = BlkIo->Media;
Capacity = MultU64x32 (Media->LastBlock + 1, Media->BlockSize);
MyPrint ("[#%d] MediaId=%d Present=%d Removable=%d Partition=%d ReadOnly=%d\r\n", ...);
MyPrint ("    BlockSize=%d IoAlign=%d LastBlock=0x%lx Capacity=%ldMB\r\n", ...);
```
