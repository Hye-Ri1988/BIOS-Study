# EC — 嵌入式控制器

## 概述

独立低功耗 MCU（8051 / Cortex-M 内核），系统关机后仍由电池供电保持运行，通过 LPC/eSPI 与 PCH 通信。在笔记本和嵌入式平台中至关重要。

## 功能

- **电源管理**：开机/关机/休眠时序控制
- **键盘矩阵扫描** + PS/2 模拟
- **温度传感器 + 风扇转速**（Thermal/Fan）
- **电池充放电管理** + 电量检测
- **Lid Switch（合盖检测）/ LED 指示灯**

## 开机时序

```
电源按钮 → EC 收到信号 → EC 启动电源轨 → EC 释放 RSMRST → CPU 上电 → 系统启动
```
