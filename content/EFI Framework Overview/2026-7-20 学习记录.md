# UEFI 固件六大启动阶段

## 各阶段分析

| 阶段 | 职责 | 开始标志 | 结束标志 |
| ------- | --------------------------- | ------------------------ | --------------------------- |
| **SEC** | 建立信任根，用 CPU 缓存做临时内存 | Reset Vector（CPU 取第一条指令） | 跳转到 PEI Core 入口 |
| **PEI** | 初始化内存，把资源清单交给 DXE | `PeiCore()` 被 SEC 调用 | `DXE IPL PPI` 触发 → 调入 DXE |
| **DXE** | 加载所有硬件驱动，建立完整固件服务 | `DxeMain()` 收到 HOB 列表 | `gBds->Entry()` 移交 BDS |
| **BDS** | 选择启动设备，加载 OS Loader | `BdsEntry()` 执行 | `StartImage()` 启动 OS Loader |
| **RT** | OS 运行期间，提供 Runtime Services | `ExitBootServices()` 返回 | 关机 / 休眠 / 崩溃 |
| **AL** | OS 终止后固件重新接管 | OS 终止（S3/S4/S5/崩溃） | 系统断电 或 重新进入 SEC |

## SEC Phase — Security

1. **信任根建立**：SEC 代码烧死在 Flash 受保护区域，假设无法被篡改，验证 PEI 阶段代码的完整性
2. **CPU 自检**：执行 BIST（Built-In Self Test）
3. **Cache-as-RAM 初始化**：配置 MTRR 将 CPU 缓存设为 no-eviction 模式，充当临时内存（至少 4KB）
4. **定位固件**：找到 Boot Firmware Volume (BFV)
5. **移交信息打包**：整理 PEI 需要的信息传递给 PEI Foundation

开始标志：**Cache-as-RAM 初始化 (CAR Init)**

## PEI Phase — Pre-EFI Initialization

PEI 分两段运行，以内存初始化为分界：

**第一段：Pre-Mem（CAR 环境）**
1. 调度 Pre-Mem PEIMs，按依赖关系加载早期模块
2. 芯片组早期初始化，让内存控制器可工作
3. **MRC 内存训练**：校准 DDR 信号时序（DQS 延迟、ODT 阻抗、Vref 电压），启动中最耗时的步骤之一
4. `InstallPeiMemory()` 注册训练好的 DRAM 为可用内存

**第二段：Post-Mem（DRAM 环境）**
5. **PEI Re-Entry**：PEI Foundation 从 CAR 复制到 DRAM 重新运行
6. 调度 Post-Mem PEIMs：硅初始化（FSP-S）、策略配置等
7. **创建 HOB 列表**：内存可用性、固件位置、CPU 信息等写入 HOB 链表
8. 触发 `EfiEndOfPeiSignal` PPI
9. 调用 DXE IPL：找到并执行 `DXE IPL PPI`，由它加载 DXE Foundation

开始标志：`PeiCore.Entry(FFF889FE)`（第一段）、`PeiCore.Entry(64C58400)`（第二段）

结束标志：`EfiEndOfPeiSignal PPI 被安装 → 回调执行完毕 → DxeIpl->Entry() 调入 DXE`

## DXE Phase — Driver Execution Environment

代码量最大、运行时间最长的阶段。DXE Foundation 先建好运行环境，再加载执行所有 EFI Driver。

**Foundation 初始化：**
1. 解析 HOB 列表，读取 PEI 留下的资源清单
2. 初始化内存服务（页面分配器和池分配器）
3. 初始化 Handle 服务（Handle-Protocol 数据库）
4. 初始化 Image 服务（PE/COFF 镜像加载器）
5. 初始化 GCD 服务（管理内存/IO/MMIO 空间）
6. 创建 EFI System Table
7. 注册 Architectural Protocol 回调，所有 Required 架构协议就绪后 Dispatcher 才开始加载驱动

**Dispatcher 调度驱动：**
8. 扫描 Firmware Volume，找到所有 FFS 文件
9. 按依赖表达式调度（Depex Section，逆波兰表达式）
10. 加载执行 EFI Drivers：Early DXE Drivers → UEFI Driver Model Drivers

**驱动执行成果：**
11. 架构协议就绪：CPU Arch、Timer Arch、RTC Arch、Reset Arch、Security Arch
12. PCI 总线枚举，为每个设备安装 PCI IO Protocol
13. 设备初始化：显卡（GOP）、USB、SATA/NVMe、网卡等
14. ACPI 表创建与提交
15. SMBIOS 表创建
16. `EndOfDxe` 信号，标志 DXE 主体工作完成

## BDS Phase — Boot Device Selection

1. 设置固件厂商信息（`gST->FirmwareVendor`、`FirmwareRevision`）
2. 规范化全局 UEFI 变量
3. 连接控制台设备（键盘、显示器、串口）
4. 从 NVRAM 读取 `BootOrder` → `Boot####` 启动项列表
5. 枚举启动设备（硬盘、USB、光驱、PXE）
6. 按优先级尝试启动
7. 可进入 Setup UI（DEL/ESC/F2 进 Setup；F7/F12 弹出 Boot Menu）
8. 触发 `ReadyToBoot` Event
9. 调用 `gBS->LoadImage()` + `gBS->StartImage()` 启动 OS Loader

## 阶段对照速查

| 阶段 | 干了什么 | 入口函数 | 出口 |
| ------- | ---------------------------- | ------------ | ----------------------------- |
| **SEC** | CPU 缓存当内存用，验证代码没被篡改 | Reset Vector | → 跳转 `PeiCore()` |
| **PEI** | 训练内存让它能用，写清单(HOB)给下家 | `PeiCore()` | → `DxeIpl->Entry()` 调入 DXE |
| **DXE** | 加载所有硬件驱动，建好固件服务 | `DxeMain()` | → `gBds->Entry()` 移交 BDS |
| **BDS** | 决定从哪启动，加载 OS Loader | `BdsEntry()` | → `StartImage()` 启动 OS Loader |
