# MyUefiApp：UEFI Key Detector（UEFI APP）

## 任务

**UEFI Application**——在 Shell 环境手动运行的独立 .efi 程序，做键盘检测演示：实时显示每次按键的 ScanCode 和 Unicode，识别 F1-F12，ESC 退出。

## 实现目标

| # | 需求 | 状态 |
|---|---|---|
| 1 | 清屏 + 显示 "UEFI Key Detector" 横幅 | ✅ |
| 2 | 显示 UEFI Firmware Vendor | ✅ |
| 3 | 实时捕获按键（不回车） | ✅ |
| 4 | 显示 ScanCode（十六进制）+ Unicode | ✅ |
| 5 | F1-F12 额外提示 [Function Key Fx detected!] | ✅ |
| 6 | 累计按键次数 Key #01, #02… | ✅ |
| 7 | ESC 退出 + 总按键次数 | ✅ |
| 8 | 退出前延时 3 秒 | ✅ |

## 与 DXE 驱动任务的关键区别（本任务核心认知）

| | DXE_DRIVER（MyRTServices 等） | UEFI_APPLICATION（MyUefiApp） |
|---|---|---|
| 运行环境 | POST 阶段，Depex 自动调度 | **Shell 里手动运行** |
| 入口 | UefiDriverEntryPoint | **UefiApplicationEntryPoint** |
| 屏幕 | Post Manager | **gST->ConOut 直接 Print** |
| Depex | 必须有（写错会出事） | **不存在，INF 无 [Depex] 段** |
| 按键 | 跟 TSE 抢键（MyRTServices 踩过） | **APP 运行时 Shell 等待，键盘独占，阻塞等键安全** |

### INF 要点

```inf
MODULE_TYPE = UEFI_APPLICATION
ENTRY_POINT = MyUefiAppMain
[LibraryClasses]
  UefiApplicationEntryPoint
  UefiBootServicesTableLib
  UefiLib        # Print()
  PrintLib       # UnicodeSPrint()
无 [Depex]、无 [Protocols]
```

### 主程序流程

```
ClearScreen → 横幅 → FirmwareVendor/Revision
  ↓
while(TRUE):
  WaitForEvent(ConIn->WaitForKey) + ReadKeyStroke   ← 实时按键
  KeyCount++ → "Key #%02d : Scan = 0x%02x , Unicode = %s"
  ScanCode ∈ [SCAN_F1, SCAN_F12] → "[Function Key F%d detected!]"
  ScanCode == SCAN_ESC → break
  ↓
"ESC pressed. Total keys: N" → Stall(3s) → ClearScreen → return
```

### 三个设计要点

1. **阻塞等键安全**：`WaitForEvent` 阻塞等待——APP 运行期无竞争者（Shell 在等待），不适用任务 8"DXE 驱动死等"的教训
2. **ScanCode 用枚举常量**：`SCAN_F1=0x0B`~`SCAN_F12=0x16`（连续）、`SCAN_ESC=0x17`——不硬编码（值随 MdePkg 版本变化，F10 在本项目是 0x14）
3. **F 键 Unicode 显示 `(none)`**：功能键 `UnicodeChar==0` 无字符

## 知识点沉淀

1. **UEFI_APPLICATION vs DXE_DRIVER**：前者用户运行、环境现成、无 Depex；后者系统调度、环境逐步就绪、Depex 决定时机
2. **控制台直用**：APP 里 `gST->ConIn/ConOut` 直接可用（Shell 已初始化），不需要 Post Manager
3. **UefiLib 的 Print**：`%s` 是 CHAR16*（与标准 C 不同），`%d`/`%x` 正常
4. **FirmwareRevision**：高 16 位主版本、低 16 位次版本
5. **Stall vs Timer**：简单延时用 `gBS->Stall(微秒)`；需要并发/可中断才用 Timer 事件
