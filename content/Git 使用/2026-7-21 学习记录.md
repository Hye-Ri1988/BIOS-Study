# Git 使用

## 准备

- [x] 安装 Git 并配置用户信息

```bash
git config --global user.name "tianjunyou"
git config --global user.email "tianjunyou@email.com"
```

- [x] 安装 TortoiseGit 并安装中文语言包

## 创建本地仓库并推送至远程

### 1. 进入 Git Bash

在要管理的文件夹中右键空白处进入 Git Bash（也可用 GUI 界面，看个人习惯）。

### 2. 初始化本地仓库

```bash
git init
```

### 3. 将文件添加至暂存区

```bash
git add .
# or
git add <文件名>
```

### 4. 提交至本地仓库

```bash
git commit -m "message"
```

### 5. 在 GitLab 中创建远程空仓库

> [!warning] 注意
> 不勾选 "Initialize repository with a README"

获取远程仓库地址（HTTPS 或 SSH）。选 SSH 需要先生成 SSH Key 并添加到 GitLab。

> [!info] 配置 SSH Key
> ```bash
> ssh-keygen -t rsa -C "tianjunyou@cvte.com"
> ```
> 打开 `C:/User/用户名/.ssh` 路径下的公钥文件，复制全部内容，粘贴到 GitLab 的 SSH Keys 设置中。（GitLab 基础教程的界面已更新，需按当前界面操作）

### 6. 关联远程仓库

```bash
git remote add origin <仓库地址>
```

### 7. 推送文件至远程仓库

```bash
git push -u origin master
```

之后修改源码再次提交推送：`git add .` → `git commit -m "message"` → `git push`
