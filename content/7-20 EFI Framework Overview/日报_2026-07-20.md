# BIOS 学习日报 — 2026.07.20

## 学习内容

1. **UEFI 启动流程**：理清了 SEC→PEI→DXE→BDS→RT→AL 六阶段的职责与交接方式，SEC 建信任根、PEI 训内存写 HOB、DXE 加载全部驱动、BDS 选启动项。

2. **串口日志分析**：对照 MTL 平台日志，标注了 8 个阶段分界点（CAR Init → PeiCore → MRC → EndOfPei → DxeCore → EndOfDxe → BDS Handoff），现在能按阶段"断句"了。

3. **ROM 结构拆解**：用 UEFITool 分析了一个 Tiger Lake 32MB BIOS ROM，找到 FV_RECOVERY（含 48 个 PEIM）、FV_MAIN（含约 233 个 DXE 驱动），确认 FV_MAIN 使用 LZMA 压缩存放。

## 总结

能把启动流程和实际日志/ROM 结构对应起来了，不再只停留在纸面。
