# 任务9：MyStackGuardLib 栈溢出检测库 + LibraryMapping

## 目标

创建一个 DXE 阶段可用的 Library，通过 LibraryMapping 机制让其他驱动能调用。库本身实现栈 canary 检测功能，写一个演示驱动在 SignOn 界面展示效果。

## StackGuard 检测原理

没有做真溢出，因为真溢出了三重故障系统直接重启，什么都看不到。

做法：在当前函数栈帧上方 512 字节处写一个固定值 0xDEADBEEFDEADBEEF 作为 canary。正常运行时这个值不变。演示时主动往这个地址写脏值模拟被踩穿的效果。每次检查读回来比对，不相等就报 OVERFLOW。

```c
// Init：在当前栈上取地址，+512 偏移写 canary
mCanaryAddr = (UINTN)&LocalVar + 512;
*(volatile UINTN*)mCanaryAddr = 0xDEADBEEFDEADBEEF;

// Check：读回比对
return *(volatile UINTN*)mCanaryAddr != 0xDEADBEEFDEADBEEF;

// Simulate：主动写脏模拟溢出
*(volatile UINTN*)mCanaryAddr = 0xCAFEBABECAFEBABE;
```

演示驱动在 SignOn 界面执行流程：Init → Check 1(OK) → Simulate → Check 2(DETECTED) → Post Manager 输出。

## LibraryMapping 三步

### 一：.dec 声明库类

`OemJYTianPkg.dec` 的 `[LibraryClasses]` 段：

```
MyStackGuardLib | MyStackGuard.h
```

告诉构建系统"存在一个叫 MyStackGuardLib 的库类，头文件是 MyStackGuard.h"。仅此而已，不指定实现在哪个 INF。

`[Includes]` 段已有 `JYTianLibModule` 路径，所以消费者 `#include <MyStackGuard.h>` 能找到头文件。

### 二：.sdl LibraryMapping 映射到 INF

```sdl
INFComponent
    Name  = "MyStackGuardLib"
    File  = "MyStackGuardLib.inf"
    Package  = "OemJYTianPkg"
    ModuleTypes  = "BASE"
    Token = "MyStackGuardLib_INF_SUPPORT" "=" "1"
End

LibraryMapping
    Class  = "MyStackGuardLib"
    Instance  = "OemJYTianPkg.MyStackGuardLib"
    ModuleTypes  = "PEIM DXE_DRIVER"
End
```

`make sdl` 把这两段翻译到 `Platform.dsc`：

- **INFComponent → Components 段**：`OemJYTianPkg/JYTianLibModule/MyStackGuardLib.inf`——编译指令，把这个 INF 描述的源文件编译成 `.lib` 中间产物。没有这一行，源码不会被编译
- **LibraryMapping → LibraryClasses 段**：`MyStackGuardLib|OemJYTianPkg/JYTianLibModule/MyStackGuardLib.inf`——链接指令，某个驱动声明了 MyStackGuardLib 时，将上面的 `.lib` 链接进去

### 三：Consumer INF 声明依赖

`MyStackGuardDemo.inf` 的 `[LibraryClasses]` 段：

```
MyStackGuardLib
```

EDK2 构建系统看到这一行，去 `Platform.dsc` 的 LibraryClasses 段找 `MyStackGuardLib` 对应的 INF，链入 `MyStackGuardLib.lib`。链接时 `MyStackGuardInit()` 等符号从 `.lib` 解析出来，Consumer 的 `.efi` 里就有了这些函数。

### 三者关系

```
dec [LibraryClasses]   →   声明抽象概念
sdl LibraryMapping     →   映射抽象到具体 INF
Consumer INF           →   声明要用这个抽象
                        ↓
              EDK2 按映射找到 INF，链入 .lib
```

少了任何一个都走不通：
- 没 dec：构建系统不认识 MyStackGuardLib 这个名字
- 没 sdl LibraryMapping：知道名字，不知道对应的 INF 在哪，报 "not resolved"
- Consumer INF 没写 LibraryClasses：不会链接 .lib，调函数时链接报 undefined symbol
