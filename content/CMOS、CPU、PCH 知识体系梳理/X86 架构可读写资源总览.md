# X86 架构可读写资源总览

CPU 通过不同的地址空间与外设通信，共四大类访问方式：

| 空间类型 | 访问方式 | 关键特性 |
|---------|---------|---------|
| **Memory 空间** | 物理地址直接访问 | 段地址×16 + 偏移地址 |
| **IO 空间** | IN/OUT 指令 | 独立于内存，地址范围 0000h~FFFFh |
| **ISA 总线** | Index/Data 间接访问 | 典型：0x2E/0x2F、0x70/0x71 |
| **PCI 总线** | 配置空间访问 | IO 端口 0xCF8/0xCFC |

## 1.1 Memory 空间访问

**物理地址计算**：`物理地址 = 段地址 × 16 + 偏移地址`

- 段地址：16 位段寄存器值；偏移地址：16 位或 32 位偏移
- 直接编址，访问速度最快（CPU 直连），包含 RAM、ROM、MMIO

**RU 工具操作**：启动 RU.efi → 按 `F5` → 选择 **Memory** → 输入物理地址 → 查看/修改 → 按 `F7` 切换数据宽度（Byte/Word/DWord/QWord）

## 1.2 IO 空间访问

X86 特有的 IO 独立编址，用专用指令 `IN`/`OUT`，端口地址与内存地址互不干扰，范围 0000h~FFFFh。

**常见 IO 端口**

| 端口地址 | 设备/功能 | 说明 |
|---------|----------|------|
| 0x60/0x64 | 8042 KBC | 键盘控制器 |
| 0x70-0x71 | CMOS/RTC | CMOS 读写端口 |
| 0xCF8/0xCFC | PCI Config | PCI 配置空间 |
| 0x3F8-0x3FF | COM1 | 串口 1 |

**RU 工具操作**：`F5` → **IO Space** → 输入端口地址 → 查看/修改

## 1.3 ISA 总线空间访问

**Index/Data 间接访问方式**：
1. 先写 **Index 端口**（指定偏移地址）
2. 再读写 **Data 端口**（获取/设置数据）
3. 典型端口对：`0x2E/0x2F`、`0x70/0x71`
4. 广泛用于 Super I/O、EC、CMOS 等

| 端口 | 设备 |
|------|------|
| 0x2E/0x2F | Super I/O (LPC) |
| 0x4E/0x4F | 备用 Super I/O |
| 0x70/0x71 | CMOS/RTC |
| 0x62/0x66 | EC（嵌入式控制器） |

**RU 工具操作**：`F5` → **ISA** → 输入 Index/Data 端口

## 1.4 PCI 总线空间访问

通过 IO 端口 0xCF8/0xCFC 访问：
- `CONFIG_ADDRESS (0xCF8)`：32 位地址寄存器
- `CONFIG_DATA (0xCFC)`：32 位数据寄存器

**CONFIG_ADDRESS 格式**

```
Bit31    = Enable (1=启用)
Bit[23:16] = Bus 号
Bit[15:11] = Device 号
Bit[10:8]  = Function 号
Bit[7:2]   = Register 偏移
```

支持范围：256 Bus × 32 Dev × 8 Func

**PCI Configuration Space 关键字段**

| Offset | 字段 | 大小 | 说明 |
|--------|------|------|------|
| 0x00-0x01 | Vendor ID | 16-bit | 设备厂商 ID |
| 0x02-0x03 | Device ID | 16-bit | 设备 ID |
| 0x04-0x05 | Command | 16-bit | 命令寄存器 |
| 0x08 | Class Code | 8-bit | 设备类别 |
| 0x10-0x24 | BAR0-BAR5 | 32-bit×6 | 基地址寄存器 |

**RU 工具操作**：按 `F6` 可直接选择 PCI Bus/Device/Function，无需手动构造 CONFIG_ADDRESS；也可 `F5` → **PCI** → 输入 BDF。
