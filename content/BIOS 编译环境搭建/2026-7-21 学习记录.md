# BIOS 编译环境搭建

## 编译前需要准备的工具

- [x] WinDDK / EWDK（提供 x86/x64 交叉编译器，二者选其一）
- [x] AMI Build Tools（AMI 编译工具集）
- [x] VEB (Visual eBIOS) — 集成开发环境
- [x] SVN — 获取要编译的项目源码

> [!warning] 注意
> 所有工具放在统一目录下，路径不能含中文及空格，避免编译报错。

## 配置 VEB 编译环境

1. 打开 VEB Tool
2. 菜单栏 `Tools` → `Options`，配置编译器和工具路径
3. `File` → `Open Project`，找到源码中的 `.veb` 文件打开
4. 按 `F9` 开始编译

## 编译报错情况

> [!danger] 报错原因
> ==源码路径名太长，导致报错。==

### 解决措施

> [!done] ==更换源码存放路径即解决。==
