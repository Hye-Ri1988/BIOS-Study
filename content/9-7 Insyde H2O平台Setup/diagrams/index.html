3. 数据流全景图（字节 ⇄ 字符串边界）

内部只存字节（struct），只在浏览器索要时才生成字符串；BlockToConfig / ConfigToBlock 就是边界转换。

4. IFR 结构树（formset → form → question + varstore）

浏览器解析 IFR opcode 成树；varstore / NVRAM 变量 / struct 三者字节布局严格对应（2 字节）。

5. classguid / class / subclass → Main/Advanced 归类机制

它们不是 Main/Advanced 本身，而是分类标签；落到哪个 Tab 取决于平台源码映射表。类比：会议室 + 会议类型回执。
