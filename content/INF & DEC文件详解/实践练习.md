# Module 创建实战：PEI DXE SMM UEFI LIBRARY

准备工作：先创建自己的 eModule，选择在 `OemPkg\Function\JYTianModule` 下创建。

## 练习一：创建一个简单的 PEIM，在 PEI 阶段打印调试信息

### 创建 JYTianModulePei.inf

- `[Defines]`：参考其它已写好的模块（如 WatchDogPei.inf），修改 BASE_NAME、FILE_GUID、ENTRY_POINT 即可
- `[Sources]`：写模块要引用的 .c/.h 文件（JYTianModulePei.c）
- `[Packages]`：根据模块功能确定。本次用 DEBUG() 宏 → 打开 MdePkg/MdePkg.dec 的 `[LibraryClasses]`，找到 `DebugLib|Include/Library/DebugLib.h` → 写 `MdePkg/MdePkg.dec`
- `[LibraryClasses]`：写 `DebugLib`；PEIM 还必须有入口点库——`MODULE_TYPE=PEIM` + `ENTRY_POINT` 需要 `PeimEntryPoint`（提供真正的 `_ModuleEntryPoint` 去调用我们的 `ENTRY_POINT`）
- `[Ppis]`：只在代码 LocatePpi/InstallPpi 某个 PPI 时才列，这里用不上

> `[LibraryClasses]` = 声明"我调了这些库 API"（类似 C 开发中 include "stdlib"）。具体用哪个实例实现，由 **DSC** 映射库实例。

### 创建 JYTianModulePei.sdl

参考看门狗的 sdl 文件，将 TOKEN 下的 Name 修改为 "JYTianModule_SUPPORT"，INFComponent 下 Name = "JYTianModulePei"。

### 创建 JYTianModule.cif

```xml
<component>
    name = "JYTianModule"
    category = ModulePart
    LocalRoot = "OemPkg/Function/JYTianModule/"
    RefName = "JYTianModule"
[files]
"JYTianModule.sdl"
[INF]
"JYTianModulePei.inf"
<endComponent>
```

### 创建 JYTianModulePei.c

> 用了 `DebugLib` → 既要 `[LibraryClasses]` 写 `DebugLib`（告诉 DSC 选哪个实现），也要 `.c` 里 `#include <Library/DebugLib.h>`（让编译器看到声明）。

```c
#include <PiPei.h>
#include <Library/DebugLib.h>

EFI_STATUS
EFIAPI
MyTestPeiInit(
  IN EFI_PEI_FILE_HANDLE  FileHandle,
  IN const EFI_PEI_SERVICES **PeiServices
  )
{
  DEBUG((DEBUG_INFO, "Hello PEIM, This is a test message.\n"));
  return EFI_SUCCESS;
}
```
