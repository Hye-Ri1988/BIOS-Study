# 任务1：通过GOP输出当前显示器分辨率、刷新率信息


# 一、实现思路：

## <font color="#000000">1.计算刷新率</font>

标准EDID中存放了128字节的数据，存放在显示器的E2PROM中，存放的数据如下表：

| 字节范围    | 内容                                            |
| ------- | --------------------------------------------- |
| 0–7     | 固定头（`00 FF FF FF FF FF FF 00`），用来校验是不是有效 EDID |
| 8–17    | 厂商 ID（EISA ID）、产品代码、生产年份周                     |
| 18–53   | 屏幕尺寸、纵横比、电源管理、颜色特性、DDC 能力等                    |
| 54–125  | 4 个 18 字节的**详细时序描述符（DTD）**——即你的代码在解析的部分       |
| 126–127 | 扩展块数量 + 校验和                                   |

这里我们主要目的是要去读DTD中的数据，
如下表：

|字段|字节|作用|
|---|---|---|
|**像素时钟**|0–1|该时序的像素时钟频率（单位 10 kHz，小端序）|
|**水平有效像素**|2–3|每行显示的像素数（如 1920）|
|**水平消隐**|3–4|每行的消隐区像素数|
|**垂直有效行数**|5–6|每帧显示的行数（如 1080）|
|**垂直消隐**|6–7|每帧的消隐行数|
|**水平同步**|8–9|行同步信号的偏移与脉宽|
|**垂直同步**|10–11|帧同步信号的偏移与脉宽|
|**尺寸/边框/标志位**|12–17|画面大小、隔行标志等|

这里需要通过像素时钟来判断这是否是一个真正的时序描述符，然后再去读里面的数据。

之后计算得出刷新率：

一个时序要形成一帧画面，实际扫描行 = **有效行 + 消隐行**（`VTotal`），每行实际像素 = **有效像素 + 消隐像素**（`HTotal`）：

```
刷新率 = 像素时钟 ÷ HTotal ÷ VTotal
       = 像素时钟 ÷ (有效水平 + 消隐) ÷ (有效垂直 + 消隐)
```

比如 1920×1080@60Hz：
- 像素时钟 ≈ 148.5 MHz
- HTotal = 2200（1920 + 280 消隐）
- VTotal = 1125（1080 + 45 消隐）
- 148.5M ÷ 2200 ÷ 1125 ≈ **60 Hz**
